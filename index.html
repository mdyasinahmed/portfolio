TARGET: Q1 JOURNAL PUBLICATION

Data-Driven Healthcare Resource Realignment in Bangladesh: A Geospatial & Machine Learning Approach

The Problem I Picked

In Bangladesh, doctors and hospital beds are often distributed based on administrative or political factors rather than real community needs. Building expensive new hospitals everywhere is economically unfeasible, leaving many rural communities underserved.

My Proposed Solution

A data-driven Decision Support System that analyzes travel times (via road networks) and actual hospital bed pressure. Instead of building new facilities, it mathematically identifies exactly where to realign existing doctors, beds, and equipment across Upazila Health Complexes (UHCs) for maximum fairness.

Key Contributions
  • Modeled real-world travel accessibility using Enhanced 2-Step Floating Catchment Area (E2SFCA).
  • Grouped 490+ upazilas into clear priority zones using Unsupervised K-Means clustering.
  • Measured healthcare distribution inequality using the Gini Index.
Python (GeoPandas) QGIS E2SFCA K-Means Scikit-learn Spatial Optimization
