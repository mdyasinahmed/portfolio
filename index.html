CSE 422 — Artificial Intelligence Lab

Improving Sentiment Analysis by Refining NLP Dictionary and Negation Handling

+

Tackled the limitations of lexicon-based sentiment analysis using the AFINN dictionary — especially its inability to handle complex negations — via a scope-controlled negation handler and improved tokenization.

Contributions
  • Identified key logical flaws in existing dictionary-based sentiment scoring
  • Redesigned the tokenizer to handle negations dynamically
  • Developed improved sentiment scoring logic in JavaScript
  • Proposed next-phase model integration for contextual learning
Outcome

Enhanced accuracy on real-world data, laying groundwork for hybrid ML–NLP models.

Survival Prediction for Post-HCT Patients Using Machine Learning

+

Contributions
  • Designed a machine learning pipeline for survival prediction

  • Implemented Logistic Regression, Random Forest, and SVM models
  • Interpreted clinical significance of fairness-aware outcomes
